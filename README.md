# VLA Data Augmentation Project

这是一个整合了NVIDIA Cosmos Predict2.5和GR00T-Dreams的VLA(Vision-Language-Action)数据增强项目。

## 项目结构

- `cosmos-predict2.5/`: NVIDIA Cosmos视频预测模型
- `GR00T-Dreams/`: NVIDIA GR00T机器人梦境生成框架

## 说明

本项目组合了两个NVIDIA官方仓库用于数据增强和机器人学习研究。
